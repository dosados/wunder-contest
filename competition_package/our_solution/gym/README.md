# Gym — обучение на частях train.parquet

Данные в `train.parquet`: независимые последовательности по 1000 шагов; каждая последовательность соответствует одному `seq_ix`. В `ParquetSequenceDataset` строки идут подряд: сначала 1000 строк — последовательность 0, потом 1000 строк — последовательность 1, и т.д. (см. README конкурса).

## Разбивка по половинам (по границе seq_ix)

Чтобы не резать последовательности посередине, половины считаются **по целым последовательностям**:

| Часть        | Индексы последовательностей | Описание                          |
|-------------|-----------------------------|-----------------------------------|
| **first_half**  | `[0, N/2)`                  | первая половина обучающей выборки |
| **second_half** | `[N/2, N)`                  | вторая половина                   |

Для `train.parquet` с 10 721 последовательностью:
- **first_half**: последовательности 0..5359 (5360 шт.)
- **second_half**: последовательности 5360..10720 (5361 шт.)

## Текущий скрипт: `gym/trainer.py`

- Обучение идёт **только на одной половине** train.parquet.
- Какую половину использовать задаётся константой **`TRAIN_DATA_PART`** в `trainer.py`:
  - `"first_half"` — обучение на первой половине (по умолчанию).
  - `"second_half"` — обучение на второй половине.

## Как обучать вторую модель на второй половине

1. В `gym/trainer.py` установите:
   ```python
   TRAIN_DATA_PART = "second_half"
   ```
2. Каталог для весов подставляется автоматически: для первой половины — `gym/best/`, для второй — `gym/best_second_half/`.
3. Запустите обучение: `python -m gym.trainer` (из каталога `our_solution`).

В логах будет указано, на какой части идёт обучение, например:
`Train data: second_half of train.parquet — sequences [5360, 10721) (total 5361 sequences)`.
