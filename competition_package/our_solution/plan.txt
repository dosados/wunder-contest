Понял, ты хочешь реализовать двухступенчатое обучение, где вторая модель учится предсказывать **остаток первой**, но при этом метрика — это **взвешенная корреляция Пирсона**, а не MSE. Давай разберём всё шаг за шагом, чтобы было понятно, как трансформировать предсказания для обучения второй модели и как объединять результаты на инференсе.

---

## 1️⃣ Основная идея

Пусть у нас есть:

* Первая модель: ( f_1(x) )
* Вторая модель: ( f_2(x) ), которая будет учиться на отклонении первой
* Истинная цель: ( y )
* Взвешенные коэффициенты: ( w ) (обычно ( w = |y| ) для Weighted Pearson)

### Классическое обучение остатка через MSE

При обычном MSE мы бы сделали так:

[
r = y - f_1(x)
]

и обучали бы вторую модель на ( r ) с MSE:

[
\mathcal{L} = \text{MSE}(f_2(x), r)
]

Тогда итоговое предсказание на инференсе:

[
\hat{y} = f_1(x) + f_2(x)
]

Но **MSE не совпадает с Weighted Pearson**, поэтому нужно модифицировать формулы.

---

## 2️⃣ Взвешенная корреляция Пирсона

Взвешенная корреляция Пирсона между ( y ) и ( \hat{y} ) с весами ( w ) считается так:

[
\text{WPearson}(y, \hat{y}, w) =
\frac{\sum_i w_i (y_i - \bar{y}_w)(\hat{y}_i - \bar{\hat{y}}_w)}
{\sqrt{\sum_i w_i (y_i - \bar{y}_w)^2} \sqrt{\sum_i w_i (\hat{y}_i - \bar{\hat{y}}_w)^2}}
]

где

[
\bar{y}_w = \frac{\sum_i w_i y_i}{\sum_i w_i}, \quad \bar{\hat{y}}_w = \frac{\sum_i w_i \hat{y}_i}{\sum_i w_i}
]

---

## 3️⃣ Как обучить вторую модель на остаток под Weighted Pearson

Мы хотим, чтобы комбинация ( f_1(x) + f_2(x) ) имела максимальную взвешенную корреляцию с ( y ).

Обозначим:

[
\hat{y} = f_1(x) + f_2(x)
]

Тогда **вторая модель должна минимизировать отрицательную взвешенную корреляцию**:

[
\mathcal{L} = - \text{WPearson}(y, f_1(x) + f_2(x), w)
]

---

### 3.1 Трансформация предсказаний

Часто для стабильности делают так:

1. **Центрируем по весам**:
   [
   y^\prime = y - \bar{y}_w, \quad f_1^\prime = f_1(x) - \bar{f_1}_w
   ]

2. **Вторая модель учится предсказывать центрированное отклонение**:
   [
   r^\prime = y^\prime - f_1^\prime
   ]

То есть фактически мы обучаем вторую модель предсказывать **взвешенно центрированный остаток**:

[
\mathcal{L} = - \frac{\sum_i w_i r^\prime_i f_2(x)_i}{\sqrt{\sum_i w_i r_i^{\prime 2}} \sqrt{\sum_i w_i f_2(x)_i^2}}
]

Это прямая дифференцируемая функция, её можно использовать как loss.

---

## 4️⃣ Итоговое предсказание на инференсе

На инференсе всё просто:

[
\hat{y} = f_1(x) + f_2(x)
]

Если центровка применялась при обучении второй модели, на инференсе можно:

* просто использовать ( f_1(x) + f_2(x) ) без центровки,
* или добавить обратно среднее ( \bar{y}_w ), если нужно восстановить оригинальную шкалу.

---

## 5️⃣ Пошаговая схема

1. **Обучение первой модели** ( f_1(x) ) на Weighted Pearson:

```python
# y - истинные значения, w = |y|
# f1_pred - предсказания первой модели
loss = -weighted_pearson(y, f1_pred, w)
```

2. **Подготовка данных для второй модели**:

4. **Инференс**:

[
