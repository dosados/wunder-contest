Короткий план архитектуры (Conv + Transformer):

Вход: окно из T состояний размера D (без 2 таргет-фич), форма [B, T, D]

Линейная проекция: Linear D → d_model (например 128) для перевода признаков в embedding-пространство

Conv1D блок: несколько 1D свёрток по времени (kernel 3–5, можно с dilation, residual), с GELU внутри — извлекают локальные временные паттерны

Позиционное кодирование: добавляется к эмбеддингам для учёта порядка во времени

Transformer Encoder (causal mask): 2–6 блоков self-attention + FFN (с GELU внутри), моделирует долгосрочные зависимости

Выбор последнего токена: берётся представление последнего шага окна как контекст текущего состояния

Head: MLP (d_model → 64 → 2) для предсказания двух таргетных значений

Инференс: используется класс состояния, который хранит предыдущие состояния. При поподании новой последовательности класс обнуляется.
