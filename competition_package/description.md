# Hybrid Conv + Transformer для предсказания поведения рынка

## 1. Постановка задачи

Имеется набор последовательностей длиной T = 1000.

Каждый момент времени:

x_t ∈ R\^D

где D --- признаки состояния рынка: - цены уровней стакана - объёмы -
сделки - производные признаки (spread, imbalance и т.д.)

Цель:

y ∈ R\^2

Предсказать 2 целевых поля на основе всей последовательности.

------------------------------------------------------------------------

# 2. Общая архитектура

Input (T × D) → Feature Projection → Temporal Conv Blocks → Transformer
Encoder → Pooling → MLP Head → Output (2)

------------------------------------------------------------------------

# 3. Представление данных

Форма батча:

X ∈ R\^{B × T × D}

где: - B --- batch size - T --- длина последовательности - D --- число
признаков

------------------------------------------------------------------------

# 4. Feature Projection

Linear(D → d_model)

Преобразование:

(B × T × D) → (B × T × d_model)

Назначение: - приведение признаков к общему пространству - learnable
mixing признаков

Типично: d_model = 128 или 256

------------------------------------------------------------------------

# 5. Temporal Convolution Block

Цель: - извлечение локальных временных паттернов - обработка
микроструктурных сигналов - подавление шума

Один residual Conv-блок:

Conv1D(kernel=3, dilation=k) → GELU → LayerNorm → Conv1D(kernel=3,
dilation=2k) → Residual connection

Используется 3--6 блоков с dilation: 1, 2, 4, 8, ...

Выход после Conv:

Z ∈ R\^{B × T × d_model}

------------------------------------------------------------------------

# 6. Transformer Encoder

Назначение: - моделирование дальних зависимостей - выявление рыночных
режимов - глобальная структура динамики

Структура одного слоя:

Multi-Head Self-Attention → Residual → LayerNorm → Feed Forward Network
(4×d_model) → Residual → LayerNorm

Параметры: - 4--6 слоёв - 4--8 attention heads - d_model = 128--256

Вход и выход слоя:

(B × T × d_model)

Добавляется positional encoding (learnable или относительный).

------------------------------------------------------------------------

# 7. Pooling

После Transformer:

H ∈ R\^{B × T × d_model}

Необходимо получить:

(B × d_model)

Варианты:

Mean pooling: H_mean = mean(H, dim=1)

Attention pooling: α_t = softmax(W · H_t) Output = Σ α_t H_t

------------------------------------------------------------------------

# 8. Prediction Head

MLP:

Linear(d_model → 128) → GELU → Dropout → Linear(128 → 2)

Выход:

(B × 2)

------------------------------------------------------------------------

# 9. Полный поток данных

X (B × T × D) → Linear → (B × T × d_model) → Conv blocks → (B × T ×
d_model) → Transformer encoder → (B × T × d_model) → Pooling → (B ×
d_model) → MLP → (B × 2)

------------------------------------------------------------------------

# 10. Почему архитектура эффективна

Conv часть: - локальные паттерны - микроструктура - шумоподавление

Transformer часть: - дальние зависимости - режимы рынка - глобальная
динамика

Head: - проекция представления в пространство таргета

------------------------------------------------------------------------

# 11. Рекомендуемые настройки обучения

-   Loss: Huber или MSE
-   Dropout: 0.1--0.2
-   Weight decay
-   Gradient clipping
-   Early stopping

------------------------------------------------------------------------

# Итог

Hybrid Conv + Transformer --- устойчивая и масштабируемая архитектура
для предсказания поведения рынка на основе длинных последовательностей.
