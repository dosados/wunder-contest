Датасет представляет собой таблицу, где каждая строка — снимок состояния рынка (Limit Order Book) и торговой активности в конкретный момент времени внутри последовательности.

# Поля:
seq_ix — идентификатор последовательности (независимый временной ряд).
step_in_seq — номер шага внутри последовательности (от 0 до 999).
need_prediction — флаг, нужно ли делать предсказание на этом шаге (обычно True с шага 99).

p0–p5 — признаки цен заявок на покупку (bid prices) на разных уровнях стакана.
p6–p11 — признаки цен заявок на продажу (ask prices) на разных уровнях стакана.

v0–v5 — объёмы заявок на покупку (bid volumes), соответствующие уровням цен.
v6–v11 — объёмы заявок на продажу (ask volumes), соответствующие уровням цен.

dp0–dp3 — признаки цен совершённых сделок (trade prices).
dv0–dv3 — признаки объёмов совершённых сделок (trade volumes).

t0, t1 — целевые переменные (анонимизированные индикаторы будущего движения цены), которые нужно предсказывать.

Данные организованы в независимые последовательности длиной 1000 шагов; первые шаги используются как прогрев модели, а оценка производится только на шагах, где need_prediction=True.
